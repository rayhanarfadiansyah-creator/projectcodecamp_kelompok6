GO GREEN — REDESIGN FRONTEND (TAHAP 1)

Isi:
- Login.html + Login.css
- Home1.html + Home1.css
- app.js

Cara pakai:
1. Ekstrak folder ini.
2. Letakkan file HTML, CSS, dan app.js di folder frontend project lama.
3. Asset gambar dan ikon dari ZIP lama sudah disertakan di folder ini.
4. Buka Home1.html melalui browser atau Live Server.

Catatan penting:
- Nama file utama dipertahankan.
- Login saat ini hanya validasi frontend, belum melakukan autentikasi.
- Link Google OAuth masih mengarah ke localhost:8080/login seperti file lama; endpoint tersebut harus tersedia di backend.
- Angka poin dan reward di Home1 adalah data contoh dari tampilan lama. Kartu status laporan menampilkan tanda — agar tidak mengarang data.
- Link menu selain anchor dan Login masih memerlukan halaman/fitur lanjutan.
- CSS dibuat baru karena file Login.css dan Home1.css tidak ikut diunggah.
